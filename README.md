# 🎬 Netflix Clone

> A Netflix-inspired web application built with React as a Proof of Concept (POC).

## 📖 Overview

Netflix Clone is a learning-focused project created to explore modern React development by recreating the core user interface and user experience of a streaming platform similar to Netflix.

The project helped me gain practical experience with React, component-based architecture, routing, responsive design, and Firebase Authentication.

This application was built purely for learning and experimentation and is **not affiliated with or endorsed by Netflix**.

---

## ✨ Features

- 🎥 Netflix-inspired user interface
- 📺 Browse movies and TV shows
- 🔐 User Authentication using Firebase
- 📱 Responsive design
- ⚛ Reusable React components
- 🎨 Modern and clean UI

---

## 🛠 Tech Stack

- React
- JavaScript (ES6+)
- HTML5
- CSS3

## 🌐 Live Demo

**Application:** https://beautiful-hummingbird-8f2323.netlify.app/

> **Note:** This project was originally integrated with Firebase Authentication for user registration and login.
>
> The Firebase Authentication configuration used during development is no longer active. As a result, **new users can still access the registration page, but authentication is not functional, and existing users cannot log in using their previously created accounts.**
>
> This project remains available to showcase the user interface, React implementation, application structure, and source code for learning and reference purposes.
